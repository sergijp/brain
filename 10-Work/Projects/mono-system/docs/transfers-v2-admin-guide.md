# Пересадки v2 — розмітка хабів адміном

(файл `~/Data/Source/mono-system/public/docs/transfers.html`, знімки поруч у `public/docs/img/`).

## Що змінилось для адміна

До v2 пересадку задавали **вручну**: на станції маршруту вказували конкретний інший
маршрут і дві станції. Одна станція = одна прописана пересадка. При 73 маршрутах
попарно зв'язати всі неможливо — у базі така пересадка була рівно **одна**.

Тепер адмін лише ставить галочку **«Пересадка»**, а комбінації рейсів система знаходить
сама. Попап із вибором маршруту-пересадки прибрано з інтерфейсу.

## Де саме галочка

**Маршрути** → редагувати → таблиця станцій → **остання колонка з галочкою**,
підписана «Пересадка», перед кнопкою видалення. Порядок колонок:

```
Номер-# · Назва зупинки · День поїздки · Час прибуття · Час відправлення ·
Кілометраж · Активний · Посадка · Висадка · Зміна автобуса · [Пересадка]
```

Не плутати зі «Зміною автобуса» — то пересадка в інший автобус **того самого** рейсу.

## ⚠️ Правило, яке легко порушити

Пошук стикує плечі **строго за `station_id`**, не за містом. У шести містах більше
однієї станції: Умань 4, Вінниця 4, Чернівці 3, Львів 3, Хмельницький / Дніпро /
Харків по 2.

Якщо позначити один вокзал із двох, частина стиковок **мовчки не знайдеться**.
Позначати треба всі станції міста і в усіх маршрутах, що через нього проходять.

Зворотний бік правильний: пошук ніколи не запропонує пересадку між двома вокзалами
одного міста — пасажира не змусять їхати через місто.

## Руками чи командою

Руками 8 міст = близько **300 галочок у 60+ формах**. Для масової розмітки є
`php artisan transfers:mark-hubs` (`--dry-run`, `--unmark`, `--city=`, `--station=`);
список міст — у `config/transfers.php` → `hubs`. Команда падає з помилкою, якщо місто
не розпізнано, — мовчазний пропуск лишив би половину хабів непозначеною.

Руками — лише окремі випадки: новий маршрут, нова станція, зняти позначку з однієї.

## Чому стиковка може не з'явитись

Порядок перевірки, від найчастішого: позначено не всі станції міста → замало часу на
пересадку (мін. 30 хв) → задовго чекати (макс. 24 год) → немає місць або ціни на
якомусь плечі → **є прямий рейс тим самим автобусом** (так і має бути: пересадку на
тому ж рейсі система не пропонує) → рейс неактивний чи продажі закриті.
