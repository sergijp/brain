# Марія — детальний план виконання (v3)

> Повне ТЗ: [[maria-tz]] · Зведення: [[maria-summary]] · Чекліст: [[maria-checklist]] · n8n: [[README]] · Ресьорч каналів: [[maria-research-channels-2026-07]]
> Легенда власників: 👤 ти · 🤖 я (Claude) · 🛠️ ERP-розробник · 🏢 провайдер

## Що змінив ресьорч 07.2026 (v2 → v3)

Свіже дослідження ([[maria-research-channels-2026-07]]) спростило три канали:

1. **Telegram: userbot ВИКИНУТО.** З 08.05.2026 (Bot API 10.0) **Telegram Business
   connected bot** підключається до особистого акаунта офіційно, безкоштовно, без
   Premium. Відповідає від імені акаунта (клієнт не бачить «бот»), ризик бану = 0,
   n8n ловить нативно (тригер «Business Message»). Telethon-адаптер більше не потрібен.
2. **Телефон: Бінотел став ОПЦІЙНИМ.** SIM у AI-платформу не заводиться напряму →
   схема **GSM-переадресація (`**21#`/`**61#`) → український SIP-DID → AI**. Достатньо
   дешевого DID (Zadarma/DIDWW) + **ElevenLabs Agents** (найкраща укр. озвучка) або
   Phonet (усе-в-одному укр. АТС з AI). Бінотел — лише як «фронт усе-в-одному».
3. **Viber: з «відкладено» → у план.** API до особистого акаунта не існує; робочий
   шлях — **AutoResponder for Viber** (Android notification-listener) з webhook у n8n.
4. **WhatsApp: Coexistence підтверджено для України.** Але спершу особистий WhatsApp →
   застосунок **WhatsApp Business** (історія зберігається). BSP: 360dialog/Wati/YCloud
   або напряму Meta; **Twilio/Infobip/Gupshup — НЕ вміють Coexistence**.

## Архітектура v3 — n8n-хаб, канали = тонкі адаптери

**n8n = єдиний мозок** (воркфлоу вже готовий: `n8n/maria-hub-workflow.json`).
Кожен канал робить POST на один webhook і відправляє відповідь назад. Промпт,
guardrails, CRM-tools, пам'ять, лог — в ОДНОМУ місці.

```
Telegram Business bot (n8n нативно) ─┐
WhatsApp Cloud API (Coexistence) ────┤            ┌→ OpenRouter (LLM+fallback)
Instagram Graph API ─────────────────┼→ n8n HUB ──┼→ CRM/TMS (розклад/місця/заявки)
Viber ← AutoResponder webhook ───────┤            └→ Журнал звернень (ERP)
Телефон: DID → ElevenLabs/Vapi/Phonet┘
```

**Чому краще:** без дублювання логіки, нові канали = +1 адаптер, три з чотирьох
месенджерів тепер на офіційних/безпечних шляхах. Hermes — повністю опційний.
