# Марія — AI нічний диспетчер: зведення

> Швидке одностороннє резюме. Повне ТЗ — [[maria-tz]].

## Що це
AI-агент **«Марія»** — нічний диспетчер міжнародних автобусних перевезень. Уночі,
поки живі диспетчери сплять, відповідає на **дзвінки й повідомлення** клієнтів:
дає розклад/ціни/наявність місць з реальних даних, приймає заявки, все фіксує.
Складне відкладає на ранок. Представляється «нічний диспетчер Марія».

## Стек (хто за що)

| Сервіс | Роль | Ціна/міс |
|---|---|---|
| 📞 **Бінотел** | телефонний фронт: вдень→люди, вночі→Марія | твій тариф |
| 🎙️ **Vapi/Retell** | голос дзвінка (STT→LLM→TTS, UA-голос) | ~$0.13/хв |
| 🧠 **Hermes** (зараз) → **n8n** (потім) | «мозок»: логіка діалогу | free + VPS |
| 🔀 **OpenRouter** | LLM-моделі + авто-fallback | токени +5.5% |
| 🗄️ **Ваша CRM/TMS** | 📖 читає розклад/місця/статус | $0 |
| 📓 **Журнал звернень** (новий модуль ERP) | ✍️ пише хто/що хотів/статус | розробка |
| ☁️ **Hostinger VPS** | хостинг | 389 ₴ (~$10) |
| 💬 **TG/WA/IG/Viber** | канали входу | ≈$0 вхідні |

## Що може / не може
- ✅ **Може:** розклад, ціни (прайс), місця/статус (CRM), FAQ, прийняти заявку
- ⛔ **Не може:** міняти ціни, платежі, обіцянки компенсацій, чужі дані, спори
- ⏸️ **Відкладає:** повернення, скарги, нестандарт → `needs-you` → дайджест
- 🔇 **Голос у месенджерах:** голосові НЕ обробляє; дзвінок у застосунку → скидає + «зателефонуйте на робочий номер». Уся розмова — лише телефон

## Режим
Нічний. Вмикається командою «приступаєш до зміни». Телефон — правило часу в
Бінотел. TZ: Europe/Kyiv.

## Дії №1 (довгі — робити першими)
1. **Бінотел** (support@binotel.ua) — зовнішній SIP + API/WebSocket ключі
2. **CRM/TMS** — API читати розклад/місця/статус (scoped-токен)
3. **ERP-розробник** — новий модуль **«Журнал звернень»** + API запису
4. **Meta Business** — верифікація для WhatsApp/IG (1–3 тижні)
5. **OpenRouter** — акаунт + кредити (⚠️ API, не підписка ChatGPT!)

## Дорожня карта

| Коли | Що |
|---|---|
| Тиждень 0 | 5 запитів вище (паралельно) |
| Тиждень 1 | VPS + Hermes + OpenRouter + Telegram → нічна Марія + CRM + журнал |
| Тиждень 1–2 | Журнал звернень + дайджест + механізм зміни |
| Тиждень 2 | Vapi/Retell + Бінотел SIP → телефон |
| Тиждень 3+ | WhatsApp → Instagram → Viber |
| Потім | міграція мозку Hermes → n8n (за тригером) |

## Бюджет
- MVP (VPS + OpenRouter + Telegram): ~$20–40/міс
- + Телефон (≈300 хв): ~$55–85/міс
- Повний (усі канали): ~$70–110/міс + тариф Бінотел

## Застереження
- Софт-агент **не має лінії** — дзвінок іде тільки через Бінотел
- **OpenRouter ≠ ChatGPT Plus** — потрібен API-баланс
- Hermes **приборкати** (learning-loop off) під строгий скоуп
- **AI-disclosure** на дзвінках — перевірити по країнах маршрутів
