## Частина 2 — методологія THE EDGE (Algorithm A → B / Storyline A → B)

### Базові формули TDA

```
X TF KL  →  X-1 TF VC                      (базова)
X TF KL  →  X-1 TF VC  →  X TF TA          (з проблемною зоною)
X TF KL  →  X-1 TF Trigger  →  X-2 TF VC   (ранній вхід)
```

Прив'язки до фіксованого ТФ немає принципово — «прив'язка до ТФ формує патернізацію».

### Словник

- **MTV** (найбільш проторгований обсяг): SNR, RB, MB
- **LTV** (найменш проторгований): FVG, IFVG
- **LIQ**: Fractal High / Low
- **VC** (Volume Confirmation) = RB / SNR / FVG
- **TA / FTA** (Trouble Area): `TF POI = TF TA`, `TF Trigger = TF FTA`
- **Strong High/Low (HRL)** — екстремум, що зняв ліквідність або ребалансував FVG → сюди ставиться SL
- **Shift** — зміщення POI: `X-1 TF VC → X TF Key Level`. Умови: доставка у FTA/TA в рамках VC + RR + `Fractal H/L → RB`

### Intraday-карта (11.2024)

Години GMT+3: LOKZ 9–12 · **Lunch 12–14 не торгувати** · NYKZ 14–17 · LCKZ 17–18.
Ризик 1%/трейд, 1%/день, 3%/тиждень, **min R 1.5**.
Ланцюг: `D1 → Bias` · `H4 → POI` · `H1 & m15 → Execution`.
POI Reaction: `H1 Trigger → m15 VC` · `H1 VC → POI Confirmed`.

### Swing-карта

07:00–19:00 GMT+3, 2%/трейд, 1 позиція/день, 3%/тиждень, 6%/місяць, ТФ Y1→m15.
**Position Adding** по `X TF Storyline → X-1 TF KLs` — саме це дало +17%/тиждень у 12.2024.

### 4 моделі входу

| Модель | Плюс | Мінус |
|---|---|---|
| **Volume Confirmation** | найвища ймовірність, чіткі критерії | часто немає тесту; VC формується прямо в FTA |
| **IDM (Induced RTO)** | SL за Strong H/L → майже неможливо пересвіпнути; вхід гарантований | вхід без підтвердження KL |
| **Market** | гарантія відкриття | гірший RR |
| **Position Adding** | множник прибутку | лише Swing / сильний OF |

Ключова теза: не існує «найкращої» моделі — треба **оптимізувати набір**. Приклад: 20 днів, 10 з правильним Bias → якщо торгуєш лише FVG-входи, реалізуєш 2 з 10.

**Induced RTO, 4 варіанти:**
```
1. X TF POI → X-1 TF Trigger → X-1 TF VC → X-2 TF IDM Execution
2. X TF POI [Liquidity] → X-1 TF VC → X-2 TF IDM Execution
3. X TF POI → X-1 TF VC → X-2 TF IDM Execution
4. X TF Trigger → X TF VC = IDM Execution
```

### RM-система (2025)

RR 1.5+ динамічний · Trade 1% / Idea 2% · Week 2% / Month 5% · **Max DD 5% → пауза 1 тиждень → ризик 1% → 0.5%**

### Зсув 2026 — двокомпонентні ідеї

Після подкастів з **Linda Raschke, Brett Steenbarger, Lance Breitstein** (Trillium) автор публічно визнав стагнацію і переписав підхід:

> «Сама змінна "у вакуумі" не дає жодної переваги, EDGE видобувається з контексту… Чому хтось має прийти в ринок і купити/продати після вас?» (Ryan Wright)

## Частина 4 — ТС AB, Крок 0, перенесення на swing

Зі словника й формул THE EDGE зібрано ТС [[ab-storyline-a-to-b|AB — Storyline A→B]] і одразу прогнано через Крок 0.

### Крок 0 (intraday) — ❌ FAIL

| | |
|---|---|
| Структурний SL за **H1** Strong H/L, EURUSD | 18.5 п (M2) / 30.1 п (M1) |
| Потрібно для RR 1.8 через гейт при вході 08:00 UTC | **≤ 9.4 п** |
| Перетин «PASS гейта І RR ≥ 1.8» | **0–1 подія зі 111** у 6 комбінаціях |

Ножиці: близькі цілі дають RR 0.2–0.4, далекі ріжуться гейтом досяжності. Той самий механізм, що вбив ТС-1.

**Побічно знайдено 4 помилки** у власній специфікації проти house-правил: відновлені скасовані KZ-гейти, заборонена резидуальна база гейта, чужі цифри ризику, невірний tilt. Усі виправлені.

### Крок 0-B (swing) — ✅ PASS

Рішення власника: варіант **B**. Формула інстанційована на рівень вище — `W1 / D1 / H4 / H1`.

| | |
|---|---|
| SL-якір | **H4** Strong H/L, 104 події за 24 міс (4.3/міс) |
| Медіанний SL | **44.5 п**, cost = 4% від SL |
| Точка B | найближчий **W1** фрактал, 168.7 п |
| **RR_net медіана** | **3.66**, 69% сетапів ≥ 1.8 |
| Частота | **2.8 сетапів/міс** |
| Утримання | медіана 1.9 дн, p75 11.5, p90 24.8 |

### Додаткові виміри

- **Спред** (Dukascopy BID/MID, N=2616): медіана **0.40 п** у торгові години; `cost_pips = 2.0` підтверджено як консервативне. Стрибок до 1.0–2.2 п на рол-овері 20:00–22:00 UTC — побічний аргумент за flat 19:00.
- **Swap-чутливість:** навіть 1.0 п/дн × 20 дн = **0.45R** з RR 3.59. Не загроза.
- **Gap через вихідні** (207 вікендів): медіана 0.30 п, p90 0.42R, p95 0.80R, **max 2.60R**. 90% нешкідливі, хвіст реальний.
- **Відхилена гілка m15:** SL 10.6 п (достатньо вузький), але RR падає до 0.66, cost = **19% від SL**, проходить 4.1% сетапів. Профіль смерті ТС-1 і ТС-3.

### Виділено окремий артефакт

[[narrative-layer|Narrative Layer]] — A→B, Why?/How?, Market State як **спільний передторговий шар** для інтрадей-ТС. Не змінює жодного правила ризику, не потребує винятків, статус `active` одразу. Б'є в задокументовану проблему ТС-2 («сетапи занадто рідкісні» — насправді бракувало фільтра **днів**, а не сетапів).

### Частина 5 — механічний прогін: ⚠️ INCONCLUSIVE

Специфікація зафіксована **до** прогону ([[ab-mechanical-spec-2026-09-16]]), прогін один, параметри не мінялись.

EURUSD M15, 2024-09 → 2026-07. Сигналів 101 → трейдів **42**.

| Вікно | N | WR | E | PF |
|---|---|---|---|---|
| ВСЬОГО | 42 | 31.0% | **+0.417R** | 1.56 |
| CTRL24 | 5 | 40.0% | +1.082R | 2.65 |
| CTRL25 | 25 | 36.0% | +0.544R | 1.82 |
| **DEV26** | 12 | 16.7% | **−0.124R** | **0.87** |

**Надлишок над нульовою моделлю** (той самий вхід і геометрія, напрямок монетою, 200 реплікацій): **+0.419R, CI [−0.018; +0.907]** — перетинає нуль. У жодному з чотирьох вікон CI не відривається від нуля.

Провалено рівно ті два критерії, які ставились проти артефактів геометрії — той самий механізм, на якому [[liquidity-sweep-88]] втратила статус.

|---|---|---|
| +0.42R | 104 | **4.8** |
| +0.30R | 203 | 9.3 |
| +0.20R | 457 | 20.9 |

**Нова цифра, якої не було в Кроці 0:** `NO_FILL` = **24% сигналів** — лімітний вхід M2 не наповнюється в чверті випадків. Очікувані 2.8 сетапів/міс насправді дають **1.8**.

AB переведено в `paused`, у paper/live не виводиться.

### Частина 6 — Narrative Layer: компонент Market State спростовано

Рішення власника: AB лишається на паузі, гіпотеза «едж у дискреції» перевіряється через [[narrative-layer]].

Перед тим як чекати 30 днів наосліп, перевірив механічно той **єдиний компонент шару, що не потребує дискреції** — Market State. EURUSD, 423 дні.

Метрика: «доступний рух» = `max(hi − open, open − lo)` за 07:00→19:00 UTC.

| Стан | N | Медіана доступного руху |
|---|---|---|
| expansion | 275 | 41.2 п |
| **compression** | 103 | **42.8 п** |
| **overextension** | 45 | **55.5 п** |

- Δ (expansion − compression) = **−1.6 п**, CI [−8.8; +5.1] → **`Compression → SKIP` не має підстави**. Фільтр відрізав би 24% днів без виграшу.
- Δ (expansion − overextension) = **−14.3 п**, CI [−32.2; −5.6] → **теза «Overextension → знижена волатильність» спростована**. Такі дні — найволатильніші. Волатильність кластеризується.

Шар переписано: з **фільтра днів** він став **вимірювальним інструментом**. Єдине, що блокує — «точка B не визначена», і це вимога зв'язності, а не емпірична теза.

**Метрику перевірки змінено з E[R] на B-hit rate**, щоб не повторити пастку потужності з AB: `b_reached` бінарна і накопичується щодня (60 днів → MDE ≈ ±13 п.п.), а E[R] вимагав би сотень трейдів.

Створено: `20-Trading/Checklists/narrative-log-template.md`, `20-Trading/Journal/narrative-log.md`. Перший день логування — **2026-09-17**.

**Точки рішення:** 60 торгових днів → B-hit rate > 50%, інакше шар згортається · 120 днів → чи `GO` кращий за `WARN`.

### Частина 7 — MDE для всієї програми тестування

Найцінніше з сесії, і не про AB.

**Ключ, якого бракувало:** для фіксованої геометрії випадковий вхід влучає в TP раніше за SL з частотою `1/(1+RR)`. Для RR 1:3 це **25%**. Порівнювати треба з цим, а не з 50% чи з «PF > 1».

**Знайдений дефект:** три специфікації з чотирьох могли виконати цілі по WR і avg-win — і все одно провалити власний поріг expectancy. Арифметика, не ринок.

| ТС | WR × avg win | → E | Поріг | Виправлено |
|---|---|---|---|---|
| ТС-1 / ТС-2 | 45% × 2.0R | +0.35R | +0.40R | WR 45 → **47%** |
| NS | 40% × 2.5R | +0.40R | +0.60R | WR 40 → **46%** |
| ТС-3 | 40% × 3.0R | +0.60R | +0.50R | ✅ узгоджені |

**Перераховані цілі вибірки:**

| ТС | Було | Стало |
|---|---|---|
| ТС-2 | 30 | **85** |
| ТС-3 | 40 | **55** |
| NS | 50 | **90** |

**Наявні вибірки проти нуля 25%:** ТС-3 EURUSD 5/10 → **p = 0.078** (найближче до сигналу з усього протестованого, недотестована на 45 трейдів) · ТС-1 9/24 → p 0.121 (архівували, не дійшовши) · ТС-2 1/11 → **гірше за випадковий**.

> ⚠️ Цей розрахунок робився **тричі**, перші дві версії хибні. Причина: геометричний RR на вході плутався із заявленим `avg R per win`. Фінальна версія розділяє їх і показує виведення — [[mde-ts-program-2026-09-16]].

## Важливі рішення (ADR)

Рішення, що не потребували ADR:

| Рішення | Підстава |
|---|---|
| Не рахувати «яка модель працює» зі статистики каналу | 21 угода з R, усі прибуткові — publication bias |
| Не писати передреєстрацію за `PREREG_TEMPLATE.md` | шаблон для сліпого 2010–2019; бектест AB іде на non-blind вікнах |
| Не вводити ATR_W-гейт досяжності | немає емпіричної бази; time-stop 30 дн має |
| Тримати через вихідні + gap як проковзування | виміряно; без поправки результат завищується на ≈0.1R/трейд |
| Революцию Форекс не розробляти | воронка без розкритої механіки і без верифікації |
| Зафіксувати специфікацію прогону письмово ДО результатів | інакше пороги підбираються під число (П2) |
| Не виводити AB далі при INCONCLUSIVE | позитивна точкова оцінка без відриву CI від нуля — не підстава |
| Сліпий резерв 2010–2019 **не відкривати** | рішення власника: AB на паузі, перевіряємо через Narrative Layer |
| `Compression → SKIP` знято з шару | спростовано на 423 днях; фільтр коштував би 24% днів без виграшу |
| Основна метрика шару — B-hit rate, не E[R] | бінарна, щоденна, MDE досяжний за 3 міс; E[R] вимагав би сотень трейдів (урок AB) |
| Цілі вибірки рахувати з MDE, не призначати | ТС-2 30→85, ТС-3 40→55, NS 50→90 |
| Порівнювати WR з `1/(1+RR)`, а не з 50% | для RR 1:3 нуль = 25%; на цьому №88 втратила статус |
| Піднімати WR-поріг, а не знижувати поріг expectancy | знижувати поріг, щоб критерії зійшлись — це П2 |
