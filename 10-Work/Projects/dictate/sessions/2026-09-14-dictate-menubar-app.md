## Мета сесії

Потрібен транскрибатор рівня Wispr Flow на iMac 2017 (iMac18,3, i7-7700K, 48 GB, macOS 13.7.8).
Після аналізу готових рішень — рішення писати свій застосунок з можливістю підключити Groq/Grok.

## Виконано

| Задача | Результат |
|---|---|
| Аналіз готових рішень під Ventura + Intel | Придатні лише Handy, Wispr Flow (хмара), MacWhisper legacy. superwhisper / VoiceInk / OpenSuperWhisper вимагають macOS 14+ або Apple Silicon |
| Свій застосунок | `~/Data/Source/dictate` — Swift 5.9 / AppKit, menu-bar, 10 файлів, збирається `./build.sh --install` |
| Підключення провайдерів | STT: Groq `whisper-large-v3-turbo`, OpenAI, локальний whisper.cpp. Cleanup: xAI Grok / Groq / OpenAI через OpenAI-сумісний `/chat/completions` |
| Встановлення | `/Applications/Dictate.app` + симлінк `/usr/local/bin/dictate`, процес запущено і живе |

## Важливі рішення (ADR)

| Рішення | Чому |
|---|---|
| Писати свій, а не брати Handy | Потрібне підключення власних API-ключів (Groq/Grok) і LLM-причісування тексту, чого Handy не дає |
| Swift + SwiftPM без Xcode-проєкту | `build.sh` збирає бандл руками: менше сміття в репо, збірка з термінала |
| AVAudioRecorder замість AVAudioEngine + конвертер | Пише 16 kHz mono WAV напряму — рівно формат Whisper-API, мінус ffmpeg і ~150 рядків конвертації |
| Хмарний STT як основний, whisper.cpp як `sttFallback` | На Intel-Маку ggml Metal не працює (CPU-only), локальний шлях у рази повільніший за Groq (~200× realtime) |
| Ключі в Keychain, не в config.json | Конфіг лежить відкритим текстом і потенційно потрапляє в git |
| Toggle через Carbon `RegisterEventHotKey`, hold через `NSEvent` flagsChanged | Carbon-хоткей працює без Accessibility; push-to-talk без нього не обійтися, але Accessibility й так потрібен для ⌘V |
| Причісування LLM — некритичний крок | Якщо LLM впав, віддаємо сирий текст замість втрати всієї диктовки |

## Проблеми й як вирішили

- **Swift 5.9 concurrency**: `var result` мутувалася всередині `Task` у синхронному CLI → компілятор відмовив. Вирішено класом-коробкою `Box<T>`.
- **`--config` не створював файл**: друкував шлях без `Config.load()`. Додано ініціалізацію дефолтів.
- **TCC і ad-hoc підпис**: кожна перезбірка змінює cdhash, macOS може скинути Accessibility. Задокументовано в README (прибрати/додати застосунок у списку).

## Доробка: вікно налаштувань

Ключі через CLI виявилися незручними — додано `SettingsWindow.swift`:
поля для ключів Groq / xAI / OpenAI (у Keychain), вибір провайдера й моделі
розпізнавання, мова, підказка, причісування з кнопкою «Список моделей…»
(тягне ID за ключем через `/models`), режим хоткея, push-to-talk, спосіб вставки.

| Рішення | Чому |
|---|---|
| Головне меню застосунку збирається руками (`installMainMenu`) | Accessory-застосунок не має меню за замовчуванням, а без пункту Edit у вікні не працює ⌘V — ключ неможливо вставити з буфера |
| Кнопка «Перевірити» ходить у `/models` | Битий ключ видно одразу, а не під час першої диктовки |
| Вікно відкривається на старті, якщо немає ключа STT | Інакше перша диктовка мовчки падає в помилку |

## Доробка 2: режими, плашка, історія, інсталятор

| Що | Стан |
|---|---|
| Режими диктовки | «Як є» (без LLM), «Чисто», «Лист», «Коміт», «Англійською», «Промпт»; у кожного свій промпт і можливий власний хоткей |
| Плашка поверх вікон | Темна капсула внизу екрана: пульсуюча крапка, рівень сигналу, лічильник; далі текст. Клік відкриває історію на цьому записі |
| Історія | Окреме вікно (⌘Y): список + редагований текст, вставка назад у вікно-джерело |
| Налаштування | П'ять вкладок, зміни застосовуються одразу без кнопки «Зберегти» |
| Інсталятор | `./make-dmg.sh` → `build/Dictate-0.1.0.dmg` |
| Apple Silicon | `build.sh` бере архітектуру з `uname -m`, є `--universal` |

### Ліміти Groq на поточному ключі (знято з заголовків відповіді)

- `whisper-large-v3-turbo` — 2000 запитів
- `qwen/qwen3.8-27b` — 1000 запитів, 8000 токенів/хв

### Заміри моделей для обробки тексту

| Модель | Час |
|---|---|
| Groq `qwen/qwen3.8-27b` | 0.28 с |
| Groq `openai/gpt-oss-120b` | 0.75 с |
| OpenRouter `ling-3.0-flash-fin:free` | 3.3 с |
| OpenRouter `nemotron-3.5-lightning:free` | 85 с, при повторі 627 с |

Висновок: безкоштовні моделі OpenRouter для диктовки в реальному часі непридатні.
`nemotron-3.5-content-safety:free` — класифікатор, на будь-який текст відповідає «User Safety: safe».

## Довга історія з дозволами (три різні причини)

1. **Ad-hoc підпис** — TCC прив'язує дозвіл до хеша бінарника, кожна перезбірка його скидала. Лікування: `make-signing-identity.sh` (сталий самопідписаний сертифікат).
2. **Довіра лише в користувацькій в'язці** — tccd звіряється з системним списком. Лікування: `trust-identity.sh` (sudo, один раз). Після нього дозвіл переживає перезбірки — перевірено.
3. **`AXIsProcessTrusted` бреше** — у вже запущеному процесі віддає застаріле `false`. Лікування: `CGPreflightPostEventAccess` + вставку пробуємо завжди.

Окремо: дозвіл був виданий копії `build/Dictate.app` замість `/Applications/Dictate.app` — бінарники однакові до байта, але TCC розрізняє їх за шляхом. Тепер `build.sh --install` видаляє проміжну копію.

## Не перевірено

Наскрізний прогін розпізнавання — немає API-ключа Groq. Потрібно `dictate --set-key groq`.
