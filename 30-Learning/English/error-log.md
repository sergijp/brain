> Кожна помилка живе тут, доки не буде виправлена 3 рази поспіль без підказки.
> Повертається у warm-up через 1, 3 і 7 днів.

| Дата | Що сказав | Правильно | Правило | Повторів OK |
|---|---|---|---|---|
| 2026-09-18 | He usually *is going* to work | He usually **goes** to work | usually/always/every day → Present Simple, не Continuous | 0 |
| 2026-09-18 | Look! It *rain* | Look! It **is raining** | Look!/Listen!/now → Present Continuous | 0 |
| 2026-09-18 | I *work* with React for 3 years | I **have worked** with React for 3 years | for/since + дія триває досі → Present Perfect | 0 |
| 2026-09-18 | There *is* many problems | There **were** many problems | there was + однина / there were + множина; минулий час | 0 |
| 2026-09-18 | *Did* you ever been to London? | **Have** you ever been to London? | ever/never/already/yet → Present Perfect | 0 |
| 2026-09-18 | interested *on* | interested **in** | залежні прийменники вчаться разом зі словом | 0 |
| 2026-09-18 | We need *update* it | We need **to update** it | need/want/plan/decide + to + V | 0 |
| 2026-09-18 | If I *have* more time, I would… | If I **had** more time, I would… | Second Conditional: if + Past Simple, would + V | 0 |
| 2026-09-18 | The server *restarting* every night | The server **is restarted** every night | Passive = be + V3; без be дієслово не існує як присудок | 0 |
