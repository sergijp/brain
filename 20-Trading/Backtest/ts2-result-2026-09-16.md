# ТС-2 — дотестування

> **Загалом: нерозрізнимо від випадкового входу.** Надлишок над нулем +4.4 пп WR, CI [−8.0; +16.0].
> **Але знайдено вузьку підгіпотезу з рідкісною властивістю: NY KZ тримається на всіх трьох роках.** Це **не результат**, це кандидат на передреєстрацію — і, на відміну від решти, з **досяжною** вибіркою: бракує 12 трейдів.

## Прогін

Чесний симулятор M15, правила R1–R6. Послідовність `Judas sweep у KZ → 15m ChoCH у бік H4 bias → вхід на FVG що створив ChoCH`, SL за екстремумом свіпу, TP = найближча ліквідність (H1 свінг / PDH-PDL / межа азійського діапазону).

| | |
|---|---|
| Дані | EURUSD M15, 2024-09-01 → 2026-07-31 |
| Вікна KZ | LON 07–09, NY 12–14, SB 15–16 UTC |
| Витрати | 2.0 п, симетрично |
| EOD flat | 19:00 UTC |

### `Min RR 1:3` знову виявився нездоланним

| | |
|---|---|
| Кандидатів з повною геометрією | **92** |
| Медіанний SL | **17.6 п** |
| Медіанний TP до найближчої ліквідності | **14.5 п** |
| Медіанний RR | **0.60** |
| Проходять `RR ≥ 3.0` | **1 із 92** |

**Третій випадок поспіль.** ТС-1, ТС-3 і тепер ТС-2 — усі вимагають RR 1:3 при SL 15–25 п, тобто ціль 45–75 п, тоді як найближча структурна ліквідність на EURUSD інтрадей лежить за **14–21 п**.

> Це не три окремі невдачі, а **одна спільна геометрична несумісність**, успадкована з [[smc-playbook-v2]].

## 🔍 Підгіпотеза: NY Killzone

Розбивка по сесіях **не була передреєстрована**. Тому нижче — гіпотеза, а не висновок.

| KZ | N | WR | E |
|---|---|---|---|
| LON 07–09 | 21 | 43% | −0.276R |
| **NY 12–14** | **16** | **75%** | **+0.214R** |
| SB 15–16 | 13 | 54% | −0.111R |

### Проти нуля, окремо

| | Значення |
|---|---|
| NY: WR / E | 75.0% / +0.214R |
| Нуль: WR / E | 52.7% / −0.101R |
| Надлишок WR | **+22.3 пп**, CI **[+0.0; +50.0]** — торкається нуля |
| Надлишок E | +0.314R, CI [−0.042; +0.719] |
| Біноміальний p | **0.060** |
| **З поправкою на 3 підгрупи** | **p_adj = 0.180** |

### Чому це все ж варте уваги

**Тримається на всіх трьох роках окремо:**

| Рік | N | WR | E |
|---|---|---|---|
| 2024 | 4 | 75% | +0.187R |
| 2025 | 5 | 80% | +0.198R |
| 2026 | 7 | 71% | +0.240R |

Це відрізняє випадок від [[ts-3-inner-fvg-sniper|ТС-3 v5]], де «едж на EURUSD» розсипався на іншій парі. Тут підгрупа стабільна **в часі**, а не в одному режимі.

Плюс є механічне пояснення, а не лише число: NY KZ — єдине вікно з **перекриттям Лондона і Нью-Йорка**, тобто найбільшим обсягом. Judas sweep там має найбільше шансів бути справжньою маніпуляцією, а не шумом.

### Скільки бракує

| | |
|---|---|
| Нуль → спостережено | 52.7% → 75% (+22.3 пп) |
| N для 80% потужності | **28** |
| Маємо | 16 |
| **Бракує** | **12 трейдів** |
| Темп | 0.70/міс → **≈18 міс** форварду або 18 міс додаткової історії |

> **Це єдина гіпотеза за сьогодні з досяжною вибіркою.** Для порівняння: AB потребує 178 трейдів (роки), ТС-3 — узагалі не має вибірки.
