# Передреєстрація — round-number гіпотеза, сліпе вікно `blind2024h1`

> **Цей файл записано ДО першого читання даних.** Порядок операцій і є тим, що
> робить тест сліпим. Жоден рядок нижче не може бути змінений після того, як
> побачені числа.

## 0. Статус вікна — одноразове санкціоноване використання резерву

`~/AI/research/strategies/data/eurusd_blind2024h1_M15.csv` (січ–сер 2024) — **єдине
вікно у проєкті, яке ніколи не читалось жодним тестом**. Воно захищене guard-ом у
`lib/feature_lab.py::load_bars` (параметр `_allow_untouched_blind_reserve`).

Власник **2026-08-25** дав явний і одноразовий дозвіл витратити цей резерв саме на
round-number гіпотезу. Guard **не прибирається** — він лишається чинним для решти
коду; обхід виконується одним явним прапорцем у власному раннері
`osler/run_roundnumber_blind.py` з коментарем про санкцію.

**Після цього прогону справді сліпих даних у проєкті не залишається.** Тому:
прогін **один**, параметри **не підбираються**, результат приймається **яким вийде**.
Повторний прогін з іншими порогами/горизонтами/якорями — **заборонений**.

## 1. Гіпотеза — заявлена ДО прогону

**Знак: від'ємний.**

> Sweep рівня, **близького** до круглого числа, працює **гірше**, ніж sweep рівня,
> **далекого** від круглого числа.

Це **протилежно** очікуванням літератури — Osler (2005) і Lee (2019) прогнозують
концентрацію стоп-лоссів біля круглих рівнів і, відповідно, **сильніший** ефект від
їх зняття. У попередньому дослідженні знак вийшов зворотний.

### Джерело гіпотези (попередній прогін, НЕ це вікно)

`~/MyVault/20-Trading/Backtest/osler-horizon-2026-08-25.md`, код `~/AI/research/strategies/osler/`:

- Δ(`<5п` − `>15п`) від'ємна у **16 комірках із 16** (2 якорі × 6 горизонтів + похідні)
- проходить BH і Bonferroni на 4 з 6 горизонтів набору A
- максимум ефекту при N=8: **Δ_raw = −0.444**, CI [−0.654; −0.241], p < 0.0001,
  Δ з поправкою на нуль = **−0.425**
- відтворюється на другому якорі (`sweep_extreme`, N=8: Δ_raw = −0.379, p = 0.0005)

Вікна попереднього прогону: DEV (бер–сер 2026), JANFEB, BLIND2025, BLIND2024.
Вікно `blind2024h1` (січ–сер 2024) у ньому **не використовувалось**.

## 2. Первинна комірка — рівно одна

| Параметр | Значення |
|---|---|
| набір подій | **A** (`max_r_planned ≤ 1.0`, як торгується) |
| якір | **`swept_level`** (знята межа Asia-діапазону) |
| горизонт | **N = 8 барів M15** |
| метрика | **Δ_excess = надлишок(`<5п`) − надлишок(`>15п`)** |
| очікуваний знак | **Δ_excess < 0** |

де `надлишок(g) = mean R_real(g) − mean R_null(g)`.

### Критерій успіху — бінарний, без градацій

- **ПІДТВЕРДЖЕНО:** `Δ_excess < 0` **І** 95% CI **не містить нуля**.
- **НЕ ПІДТВЕРДЖЕНО:** усе інше — **включно** з правильним знаком при CI, що містить нуль.

### Довідкові комірки (НЕ можуть замінити первинну)

- ті самі групи на горизонтах N ∈ {1, 2, 4, 16, 32};
- другий якір `sweep_extreme`, усі 6 горизонтів;
- середня група `5-15п` (описово, без окремого тесту гіпотези);
- набір B (`max_r_planned = None`) — **не рахується взагалі**, щоб не плодити сімʼю тестів.

> **Якщо первинна комірка провалиться, а якась довідкова спрацює — це ПРОВАЛ,
> а не «частковий успіх».** Це записано до прогону навмисно.

Усе береться з попереднього дослідження **без жодної зміни**. Код імпортується
з `osler/`, не переписується.

| swing points | `left=2, right=2` |
| Asia-вікно | 23:00 попереднього дня – 07:00 UTC, мінімум 8 закритих барів |
| killzones | 06:00–08:00 і 12:00–14:00 UTC |
| `extra_asia_session` | False (з `DEFAULT_CFG`) |
| `sessions_independent` | True |
| `reclaim_max_bars` | 10 |
| `max_r_planned` | **1.0** (набір A) |
| `min_r_sl_pips` | з `DEFAULT_CFG`, без змін |

| TP | протилежна межа Asia |
| фільтр `prep_events` | ідентичний `run_osler.py::prep_events` |

### Виконання (`osler/engine.py`)
| Параметр | Значення |
|---|---|
| `COST` | **2.0** (симетрично, в R) |
| `FLATTEN_HOUR` | **19** UTC |
| вхід | open бару `fill_idx`, RAW |
| вихід | перший з: дотик SL / дотик TP / close бару горизонту / останній close до flatten |
| R | `(pnl_pips − COST) / (SL_dist + COST)` |
| TP на кроці горизонтів | **вимкнено** (`tp_pips=None`) — захисний SL only |

### Нульова модель
| Параметр | Значення |
|---|---|
| функція | `engine.build_null_sample` |
| `reps` | **40** на подію |
| матчинг | година доби входу + геометрія SL/TP реальної події, напрямок випадковий |
| пул | будні, ті самі години, `reachable_bars > 0` |
| `seed` | **1234** (дефолт функції) |

> **Примітка про seed, зафіксована до прогону.** У `run_osler.py` seed нульової
> вибірки задавався як `hash(w) % 10000` — це **не відтворювано** між процесами
> Python (рандомізація `hash()` для рядків). Тому тут seed фіксується на дефолт
> бібліотеки `1234`. Це єдине технічне відхилення, і воно зроблено **до** читання
> даних. Підбір seed під результат заборонено; альтернативні seed не прогоняються.

### Круглі рівні і групи
| Параметр | Значення |
|---|---|
| `ROUND_GRID` | **0.0050** — тобто `00` і `50` у 4-му знаку EURUSD |
| метрика відстані | `round_dist_pips(price)` — до найближчого вузла сітки, у пунктах |
| групи | `<5п` (d < 5), `5-15п` (5 ≤ d ≤ 15), `>15п` (d > 15) |
| мінімум подій у групі | **5** (як у коді); менше — комірка не рахується |

### Статистика
| Параметр | Значення |
|---|---|
| надлишок групи | `engine.boot_excess`, `iters=4000`, `seed=21` |
| різниця груп (raw) | `engine.boot_group_diff(real_<5, real_>15)`, `iters=4000`, `seed=22` |
| зсув нуля | константа `shift = mean R_null(<5) − mean R_null(>15)` |
| **CI первинної метрики** | CI від `boot_group_diff` **мінус константа `shift`** |
| рівень | двобічний 95% (α = 0.05) |
| p | двобічний бутстреп-p з `boot_group_diff` |
| MDE | `engine.mde`: 80% потужність, α = 0.05, з фактичного sd(R) групи |

> **Чому саме така CI.** Первинна метрика — різниця **надлишків**. Нульові середні
> входять у неї як фіксовані зсуви (нульова вибірка велика: ~40× подій), тому CI
> різниці надлишків = CI сирої різниці, зсунута на ту саму константу.
> Сира різниця Δ_raw звітується **додатково**, як довідкова.

## 4. Що звітується — незалежно від результату

1. Δ_excess, 95% CI, p, вердикт `ПІДТВЕРДЖЕНО` / `НЕ ПІДТВЕРДЖЕНО` — **перше речення звіту**.
2. Δ_raw як довідка.
3. n подій у кожній групі, WR%, mean R, null R, MDE.
4. **MDE рахується і читається ДО інтерпретації.** Якщо MDE перевищує спостережений
   |Δ| — результат оголошується **неінформативним**, і це говориться прямо, без
   видавання за підтвердження чи спростування в будь-який бік.
5. Довідкова таблиця всіх інших комірок, явно позначена як довідкова.

## 5. Перевірка цілісності резерву — перед прогоном

Фіксується: mtime файлу, кількість рядків, перший і останній timestamp, модальний
крок барів, кількість дублікатів timestamp, перелік дірок понад вихідні.

## 6. Заборони цього прогону

- ❌ підбирати пороги груп (`5` / `15` п), горизонти, якорі, сітку круглих рівнів;
- ❌ прогоняти повторно з іншими параметрами або іншим seed;
- ❌ змінювати первинну комірку після того, як побачені числа;
- ❌ інтерпретувати провал первинної комірки як успіх на підставі довідкових;
- ❌ редагувати `lib/feature_lab.py` (guard лишається на місці);
- ❌ використовувати `blind2024h1` у будь-якому майбутньому тесті — після цього
  прогону вікно позначається як **витрачене**.
