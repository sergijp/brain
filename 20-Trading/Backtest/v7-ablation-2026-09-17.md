# Абляція на повній базі (вер 2025 – лип 2026)

Скрипти: `Resources/edge-alexxxfx/step0/v7_ablation.py`, перевірка біасу — `fix_bias.py`, `wf_honest.py`.
Дані: Dukascopy M5 mid, 68 591 барів.

---

## 🔴 Спершу: знайдена помилка заглядання

`weekly_bias(w)` брала **H/L/C того самого тижня**, всередині якого відкривались угоди:

```python
p = pw[w]; H, L, C = whi[w], wlo[w], wcl[w]   # ← поточний тиждень
```

Тобто напрямок тижня визначався його ж закриттям. Чесна версія: біас для тижня `w` рахується з **завершеного** тижня `w−1` проти `w−2` — рівно як денний біас береться з учорашньої свічки.

| варіант | із заглядянням | **чесно** |
|---|---|---|
| базова v6 | E[R] −0.089 · ΣR −20.2 | E[R] −0.133 · ΣR −31.2 |
| −сценарії + ризик ≤5 | E[R] +0.240 · ΣR +25.4 | **E[R] +0.133 · ΣR +15.3** |
| перцентиль проти нульової | 92% | **58%** |

**Висновок перевертається.** Усі цифри нижче — чесні.

## Абляція (чесний біас): що прибрати

| зміна | n | WR | E[R] | ΣR |
|---|---|---|---|---|
| базова v6 | 235 | 31.9% | −0.133 | −31.2 |

Без межі ризику **все від'ємне**. Shift лишається єдиним компонентом, без якого різко гірше.

## Що додати: межа ризику — єдине, що працює

| **≤5 п** | **115** | **32.2%** | **+0.133** | **+15.3** |

Монотонно: що ближче вхід до якоря стопа, то краще. Це **розрив №15**, нарешті виміряний — оптимум ≈ 5 пунктів.

Premium/Discount при ризику ≤5 **не змінює нічого** (ті самі 115 угод) — фільтр надлишковий, але й не шкодить.
Сценарії A/B при ризику ≤5 віднімають: +15.3 → +11.8.

## Walk-forward (поділ 01.02.2026)

| варіант | IS (n / E[R] / ΣR) | **OOS (n / E[R] / ΣR)** |
|---|---|---|
| чесна базова v6 | 100 / −0.202 / −20.2 | 135 / −0.081 / −11.0 |
| чесн. −сценарії | 102 / −0.241 / −24.6 | 141 / −0.135 / −19.0 |
| чесн. ризик≤5 | 57 / +0.037 / +2.1 | 54 / +0.179 / +9.7 |
| **чесн. −сцен + ризик≤5** | **56 / −0.005 / −0.3** | **59 / +0.264 / +15.6** |
| чесн. −сцен + ризик≤6 | 69 / −0.014 / −1.0 | 74 / +0.208 / +15.4 |

OOS кращий за IS — протилежність підгонці. Але IS фактично нульовий, тобто перевага тримається на одній половині вибірки.

## 🔑 Головне: напрямок не має значення

| | ΣR |
|---|---|
| чесний тижневий біас + ризик≤5 | **+15.3** |
| **випадковий напрямок** + ризик≤5 (30 прогонів) | медіана **+11.8**, 5%=−19.2, 95%=+43.4 |

Перцентиль реального результату — **58-й**. Монета дає майже те саме.

**Уся виміряна перевага сидить у геометрії:** вхід не далі 5 п від якоря стопа + ціль з чистим RR ≥2 + Shift як умова готовності. Тижневий біас у цій системі — не едж.

## Чесні застереження

1. **CI95 [−0.185; +0.455] перетинає нуль.** Прибутковість не доведена.
2. n=115 за 11 місяців — ~2 угоди на тиждень.
3. Перебрано ~35 варіантів на одній вибірці. Walk-forward пом'якшує, не знімає.
4. Витрати 2.0 п симетрично; при ризику 5 п це **40% від стопа**. Чутливість до спреду критична й не перевірена.
5. Python-бектест припускає виконання **точно на рівні** (ліміт). Ринковий вхід на закритті бару дасть гірше.
