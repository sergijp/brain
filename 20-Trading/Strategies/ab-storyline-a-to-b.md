## 🎯 Філософія

Це **не патерн, а ланцюг змінних**. Ціна не «відпрацьовує сетап» — вона доставляється з точки A в точку B, і кожен крок доставки залишає слід, який можна перевірити.

```
Гіпотеза  →  Підтвердження  →  Виконання  →  Repeat
```

Три тези першоджерела, які і є еджем:

1. **Прив'язка до конкретного ТФ породжує патернізацію.** Тому вся логіка записана як `X / X-1 / X-2 / X+1`, а не як «H4 / H1 / m15». Конкретні ТФ — це лише *поточна інстанція* формули.
2. **Точка входу ≠ торгова ідея.** Ідея живе на `X TF`. Вхід — це вже питання «як монетизувати ідею з прийнятним RR», і в нього є **кілька моделей**, а не одна.
3. **Змінна «у вакуумі» не дає переваги.** `[+D1 SNR]` сам по собі не едж. Едж — у контексті: *чому хтось має прийти в ринок і купити після мене?*

## 🧭 Словник (обов'язковий до вивчення)

| Скорочення | Значення | Приклади |
|---|---|---|
| **KL / POI** | Key Level = опорна область, де очікується реакція | будь-що з трьох рядків нижче |
| **MTV** | зони **найбільш** проторгованого обсягу | SNR, RB, MB |
| **LTV** | зони **найменш** проторгованого обсягу | FVG, IFVG |
| **LIQ** | ліквідність | Fractal High / Fractal Low |
| **VC** | Volume Confirmation — підтвердження, що обсяг реально зайшов | RB / SNR / FVG на X-1 |
| **Trigger** | Fractal H/L або FVG **всередині або біля** POI; дає «дозаправку» | H1 Fractal High у H4 FVG |
| **TA** | Trouble Area — зона, що може вбити ідею. `TF TA = TF POI` | зустрічний D1 SNR |
| **FTA** | First Trouble Area. `TF FTA = TF Trigger` | зустрічний H1 FVG |
| **Strong H/L (HRL)** | екстремум, що зняв LIQ **або** ребалансував FVG → дав імпульс | сюди і тільки сюди йде SL |
| **Shift** | зміщення POI на новий KL після реакції | `X-1 TF VC → X TF KL` |
| **DR** | Dealing Range — діапазон між двома X TF екстремумами | задає Premium / Discount |

**Ключова асиметрія рівнів** (з `TDA / TA / Trigger`):
- для **MTV** (SNR/RB/MB) ключовим рівнем є S/R, який утворює сам елемент;
- для **LTV** (FVG) і **LIQ** — свій рівень, вихід за який доводить силу протилежної сторони.

## 🔢 Базові формули

```
(F1)  X TF KL  →  X-1 TF VC                       ← база, завжди діє
(F2)  X TF KL  →  X-1 TF VC  →  X TF TA           ← з проблемною зоною
(F3)  X TF KL  →  X-1 TF Trigger  →  X-2 TF VC    ← ранній вхід
(F4)  X TF TA  →  X-1 TF POI  →  X-2 TF VC        ← контр-реакція на TA
```

> **F1 діє завжди.** Наявність тригера не скасовує базу — просто підтвердження зміщується на ТФ нижче *відносно тригера*.

## 🪜 Алгоритм (5 кроків, жорсткий порядок)

### Крок 1 — Narrative на X+1 (D1)

Відповісти рівно на три питання. Письмово, до відкриття сесії.

| # | Питання | Інструменти |
|---|---|---|
| **A** | На що ціна реагує зараз? | Fractals, FVG, SNR, RB |
| **A'** | На що ціна **може** відреагувати? | те саме, вперед по ходу |
| **B** | Який KL вона досягне з високою ймовірністю? | FVG, LIQ (Fractal H/L) |

Формат запису: `X TF KL (A) → X TF KL (B)` — **ЗВІДКИ · КУДИ · ДЕ**.

> ❌ Якщо на питання **B** нема однозначної відповіді — **Narrative не сформований, день пропускається**. Не «подивимось по ходу».

### Крок 2 — Двокомпонентна перевірка ідеї

Оновлення 2026 з першоджерела. Ідея допускається до Кроку 3 тільки з **обома** компонентами:

| Компонент | Питання | Де брати |
|---|---|---|
| **Why? (Thesis / Edge)** | Чому поточна ціна несправедлива? Що саме mispriced? | календар, CME FedWatch, DXY, ставки, інтервенції |
| **How? (Execution)** | Де технічно це реалізувати? | ланцюг F1–F4 |

> Технічна змінна без «Why» = **score −2** (див. Scoring). Це прямий фікс проблеми, яку першоджерело назвало причиною власної стагнації.

**Market State** — окремий фільтр перед графіком:

| Стан | Ознака | Що торгуємо |
|---|---|---|
| **Expansion** | свіжий пробій KL, зростання діапазонів | продовження по Narrative |
| **Overextension** | інтервенція / здутий рух минулого тижня | **mean reversion**, не тренд |
| **Compression** | inside day, діапазони падають | **skip** або лише F4 |

### Крок 3 — TDA: спершу SL, потім вхід

**Це не описка. Порядок саме такий** (зі схеми `Алгоритм анализа графика`, 2026).

1. Знайти **Strong High / Low**, за яким лежить повна відміна ідеї.
2. Виміряти відстань до нього від зони POI → це **SL**.
3. Виміряти відстань до **B** → це TP.
4. `RR = (TP − cost) / (SL + cost)`.
5. **`RR < 1.8` → трейду немає.** Не «підтягнути SL», не «взяти проміжну ціль».

> Виміряно на 24 міс: медіанний RR у робочій комірці **3.66**, 69% сетапів проходять поріг. Тобто `1.8` тут — реальний фільтр, а не стеля.

> ✅ Це головна структурна відмінність від [[_archive/ts-1-reversal-at-poi|ТС-1]] і [[ts-3-inner-fvg-sniper|ТС-3]], де SL ставився метрично-тісно і едж помирав об спред. Тут SL **структурний** — його ширину диктує ринок, і якщо вона вбиває RR, ми не торгуємо, а не звужуємо стоп.

Далі — TDA вниз:

```
VC (SNR / RB / FVG)  ·  Localization (Fractal)  ·  Dealing Range (OF / Premium-Discount)
```

### Крок 4 — Вибір моделі входу

**Ядро ТС.** Одна модель = втрачені ідеї. Математика першоджерела:

> 20 торгових днів → у 10 з них Bias правильний. Якщо торгуєш **лише FVG-входи**, з тих 10 реалізуються **2**. Решта 8 — «напрямок вгадав, входу не було».

Тому моделей чотири, і вони **не взаємозамінні** — у кожної своя умова застосування.

| # | Модель | Умова застосування | SL | Плюси | Мінуси |
|---|---|---|---|---|---|
| **M1** | **Volume Confirmation** | є чистий `X-1 TF VC` після реакції на KL | за VC-елемент / Strong H-L | найвища ймовірність, чіткі критерії | тесту може не бути; VC часто формується прямо у FTA |
| **M2** | **IDM (Induced RTO)** | є Fractal H/L усередині або біля POI | **за Strong High / Low** | вхід гарантований, пересвіп майже неможливий, FTA не проблема | вхід **до** підтвердження KL |
| **M3** | **Market** | ідея підтверджена, але тесту не буде | за відміну ідеї | гарантія відкриття | гірший RR |
| **M4** | **Position Adding** | `X TF Storyline` живий + новий `X-1 TF KL` | за нові Strong H/L | множник на одній ідеї | **тільки при сильному OF** |

**Методологія M2 (Induced RTO), 4 варіанти:**
```
1. X TF POI → X-1 TF Trigger → X-1 TF VC → X-2 TF IDM Execution
2. X TF POI [LIQ] → X-1 TF VC → X-2 TF IDM Execution
3. X TF POI → X-1 TF VC → X-2 TF IDM Execution
4. X TF Trigger → X TF VC = IDM Execution
```

**Правило вибору:**
```
є чистий X-1 VC?          → M1
нема VC, але є IDM у POI? → M2
нема ні того, ні того,
  але ідея підтверджена
  і B ще далеко?          → M3 (тільки якщо RR ≥ 2.2 — платимо за відсутність підтвердження)
ідея вже в роботі і жива? → M4
інакше                    → NO TRADE
```

### Крок 5 — Trouble Area і Shift

При доставці ціни у **FTA / TA**:

```
Умови для Shift:  доставка у FTA/TA в рамках VC  +  RR ще ≥ 1.8  +  Fractal H/L → RB
Дія:              X-1 TF VC  →  стає новим X TF Key Level
```

Три правила поведінки з TA (дослівно з першоджерела):
- розглядати FTA/TA як **звичайний KL**, незалежно від напрямку ринку;
- SL ставити за **повну відміну ідеї**, а не за локальну проблемну зону;
- спиратись на **актуальний Narrative**, а не на локальні TA.

| Перезаходи в межах дня | дозволені, але в межах стоп-дня (3 мінуси) | рішення власника |
| Tilt | **3 збитки підряд → `BLOCK` до ретро** | house (`risk-rules.md`) |
| **Стоп-дня** | **3 збиткові угоди за день → торгівлю зупинено** | рішення власника 2026-09-16 |

**Аллокація на ідею** — важлива механіка, якої нема в ТС-1/2/3: 2% на ідею означає, що одну правильну ідею можна реалізувати **двома входами** (напр. M2 раніше + M4 на продовженні), а не ставити все на один тригер.

| Рівень | Ціль | Дія |

### Метрика, заради якої все робиться

Фіксувати **щодня**, навіть коли трейду не було. Це і є фальсифікований тест гіпотези з п.5 попередньої секції.
