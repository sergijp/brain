# Мультиструктура: які ТФ розмічати при роботі на M5

Джерело: NotebookLM «Trading CT», 35 джерел курсу. Запит 18.09.2026.

## 1. Де шукати POI

| ТФ | Роль |
|---|---|
| **D1** | загальний контекст, Daily Bias, глобальні зони розвороту |
| **H4 / H1** | 🔑 **головні ТФ для розмітки POI** — тут шукаються FVG, OB, Breaker і пули внутрішньої/зовнішньої ліквідності |
| **M15** | локальний IT — у скальпінгу та крипті: POI на M15, вхід на M5 |
| **M5** | **НЕ самостійна POI.** Тільки точка входу |

## 2. Офіційні зв'язки ТФ із джерел

**Класичний інтрадей (Forex):**
```
D1  (Long Term)         → контекст, напрямок розширення свічки
H4/H1 (Intermediate)    → структура, PD-матриця, розмітка HTF POI
M5  (Short Term)        → тест POI → Shift → вхід
```
Позначені в джерелах сетапи: **H4/M5**, **H1/M5**. Допускаються H4/M15–M5, H1/M3, H1/M1.

**Скальпінг:** D1/H4 → H1/M15 → M5/M1. Сетап **M15/M5**: M15 для розмітки POI і зняття ліквідності, M5 для підтвердження зламу.

## 3. Пріоритет інструментів — PD Array Matrix

Усередині імпульсу шукати в такій послідовності:

1. **Internal BSL / SSL** (внутрішня ліквідність)
2. **FVG** (цінова неефективність)
3. **Order Block (OB)**
4. **Breaker Block (BB)**
5. **Rejection Block (RB)**

> Блоки підтримки (OB/BB/RB) ідуть **останніми** за пріоритетом і найчастіше розглядаються у зв'язці з неефективностями — наприклад `FVG + OB`.

## 4. Три фільтри валідності POI

**а) Фрактальність — старший FVG завжди сильніший за молодший.**
Якщо на M15/M5 кілька FVG поспіль — піднятись на H1 і виділити **один цілісний H1 FVG**. Найкраща точка реакції — **0.5 (50%) H1 FVG**, або де рівень відкриття H1 FVG перетинається з M15 FVG.

**б) Premium / Discount.**
Висхідний тренд → усі POI вище 0.5 низькоймовірні, **відсіюються**; шукати strictly в Discount, ближче до OTE.
Низхідний тренд → валідні лише POI в Premium.

**в) Внутрішня ліквідність — головне правило сильної POI.**
POI найпріоритетніша, якщо **безпосередньо перед нею** є зняття внутрішньої ліквідності (`FVG + Internal BSL`).
⚠️ Якщо внутрішня ліквідність (EQH/EQL або компресія) стоїть **ЗА** зоною POI — така POI **слабка і буде пробита**: ліквідність слугує паливом для руху далі.

## 5. Роль M5

На M5 FVG та OB **не є самостійними старшими POI**. Вони — точки безпосереднього входу вже після того, як ціна торкнулась старшої POI (H1/H4) і зробила первинний **Shift** на M5.

```
H1 FVG / OB (тест ціною) → перехід на M5 → злам Shift → вхід від M5 FVG або M5 OB
```

## 6. Рівні входу всередині OB

| Рівень | Властивість |
|---|---|
| **Open** | найвища ймовірність заповнення. **Для Forex основна ставка — саме Open** |
| **Mean Threshold (50% тіла)** | найкращий Risk/Reward |
| **Wick (край тіні)** | найвища ймовірність спрацювання, але найширший стоп → найменший RR |

Forex: вибирати блоки з **широким тілом**; якщо OB формується послідовно із зон FVG — межі виділяти з урахуванням тіней.
Крипта: через волатильність — **завжди** з урахуванням тіней.

⚠️ Прямий вхід від будь-якого з цих рівнів **агресивний** — реакція ціни ще не підтверджена. Рекомендовано дочекатись підтвердження на молодшому ТФ у вигляді **Shift / QM** після тесту зони.

## 🔴 Що це означає для нашого детектора

Формалізація v7 бере POI з **H1-півотів + PDH/PDL + Asia H/L + PWH/PWL**. За цими правилами це **неправильний набір**:

| Правило курсу | Що в детекторі | Розрив |
|---|---|---|
| POI = FVG / OB на **H1 і H4** | піvotи й екстремуми | **зон FVG/OB немає взагалі** |
| Пріоритет: BSL/SSL → FVG → OB → BB → RB | усі рівні рівноцінні | немає ієрархії |
| POI слабка, якщо ліквідність ЗА нею | не перевіряється | немає фільтра |
| 0.5 H1 FVG як точка реакції | немає | немає |
| Shift на M5 **після тесту H1/H4 POI** | Shift сам по собі, без прив'язки до POI | **Shift не прив'язаний до зони** |

Останній рядок — найважливіший. У детекторі Shift підтверджує «екстремум сесії», а за методом він має підтверджувати **реакцію на конкретну H1/H4 POI**.
