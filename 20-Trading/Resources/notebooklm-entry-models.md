## A. SMC-моделі — робочі для нас

### 12. Ретест Ордерблоку (OB) / 0.5 FVG Imbalance

| | |
|---|---|
| **Тригер** | ціна повертається до сформованого OB або до неефективності (FVG) |
| **Вхід** | на початку межі OB **або** на **0.5 (50%)** за Фібоначчі всередині зони |
| **Стоп** | за тінь свічки OB |
| **Ціль** | найближчий пул **протилежної** ліквідності |

### 13. Захоплення ліквідності SFP / WICK

| | |
|---|---|
| **Тригер** | **тінь** пробиває Swing High / Swing Low, тіло закривається назад |
| **Вхід** | після закриття свічки SFP **або** на 0.5 Фібоначчі від гніту WICK |
| **Стоп** | безпосередньо за тінь SFP / WICK |
| **Ціль** | протилежна ліквідність |

> Це **дослівно** ваш сетап 5 січня: свіп 1.16602 → злам структури → вхід. І це та сама геометрія, що в поправці до [[ab-storyline-a-to-b]]: SL за свіп-екстремум, не за H1 Strong Low.

### 14. Three Tap Setup (TTS / патерн трьох торкань)

| | |
|---|---|
| **Тригер** | три послідовні торкання рівня, третє — з проколом |
| **Вхід** | після третього торкання, у бік розвороту |
| **Стоп** | за екстремум третього торкання |
| **Ціль** | протилежна ліквідність |

### 15. Пробиття за рахунок засадження / ліквідації

| | |
|---|---|
| **Тригер** | скупчення стопів за рівнем; рух, що їх збирає |
| **Вхід** | після зняття, у зворотний бік |
| **Стоп** | за екстремум зняття |

> №15 — це №13 іншими словами, з акцентом на *причину* (ліквідація), а не на *форму* свічки.

### 16. Pivot Points

Торгівля від розрахункових точок (класичні пивоти). Рівні механічні, але це **не** наша ліквідність — у нас рівні структурні, а не формульні. **Не беремо**, лишаю для повноти.

## C. Що з цього йде в детектор

Мій попередній детектор свіпу шукав **тільки PDH/PDL** — і на 5 січня **не побачив би** вашого сетапу взагалі, бо 1.16602 не був вчорашнім екстремумом. Список вище дає повне визначення того, що вважається ліквідністю:

```
Рівень ліквідності = будь-що з:
  • Swing High / Swing Low  (фрактал, №13)      ← головне доповнення
  • PDH / PDL                                    ← було раніше
  • PWH / PWL
  • Equal Highs / Equal Lows                     ← EQH/EQL, збігається з 4.1 каталогу EDGE
  • Asia High / Asia Low  (діапазон сесії)
  • третє торкання одного рівня (№14)
```

**Тригер входу після свіпу** (№13 + ваша розмітка 5 січня):
```
1. свіп: тінь виходить за рівень, закриття повертається
2. MSS: злам структури на M5 у зворотний бік
3. вхід: 0.5 FVG / IFVG, створеного зламом  (№12 — «0.5 за Фібоначчі»)
4. SL: за екстремум свіпу  (не за H1 структуру)
5. TP: найближча незнята протилежна ліквідність
```

Це рівно ті три параметри геометрії, що вже записані як поправка в [[ab-storyline-a-to-b]]. Тобто NotebookLM **підтвердив** поправку незалежним джерелом, а не додав нового.
