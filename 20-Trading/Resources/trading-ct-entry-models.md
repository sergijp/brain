# Trading CT — 13 моделей входу

> Ноутбук `6b2bbdc5-d0eb-4715-8665-2b74058fde29`, **35 джерел** (курс: ринкова структура, ліквідність, FVG, OB/BB, Order Flow, MMSM/MMBM, сесійні сетапи).
>
> ⚠️ **Це джерело якісно інше за [[notebooklm-entry-models|«Торгову стратегію»]].** Там 11 із 16 моделей були індикаторні (RSI/MACD/VWAP) і нам не підходили. Тут **усі 13 — ICT/SMC**, з явними тригерами, стопами й цілями. Це той самий метод, яким працює власник.

---

## A. Розворотні моделі (ядро)

### 1. Classic Quasimodo (Classic QM)

| | |
|---|---|
| **Тригер** | під час тесту HTF POI **або** зняття ліквідності (BSL/SSL) ціна формує імпульсне поглинання і виконує злам фрактального максимуму/мінімуму — **Shift** |
| **Вхід** | на поверненні (відкаті) після зламу Shift, до зон моделі |
| **Стоп** | за максимум/мінімум сформованої розворотної моделі — **за екстремум маніпуляції** |
| **Ціль** | протилежний пул ліквідності **або** проблемні зони (FTA) / статичні 3RR |

### 2. Failure Swing (FS) Reversal

| | |
|---|---|
| **Тригер** | розворот зі зламом Shift під час тесту POI, але **БЕЗ попереднього зняття ліквідності**. Найчастіше — за наявності **SMT** між активами |
| **Вхід** | на відкаті (тесті) після формування зламу Shift |
| **Стоп** | за сформований максимум/мінімум моделі |
| **Ціль** | протилежна ліквідність або FTA / 3RR |

> Відрізняється від QM рівно однією ознакою: **свіпу не було**. Замість нього підтвердження дає SMT-дивергенція.

### 3. Sell to Buy (STB) / Buy to Sell (BTS) ⭐

| | |
|---|---|
| **Тригер** | останній низхідний рух зі зняттям SSL (для STB) або висхідний зі зняттям BSL (для BTS), що стає **безпосередньою причиною** зламу найближчого свінгу (Shift) |
| **Вхід** | відразу після Shift **або** на ретесті: від усієї зони маніпуляції **або від 0.5 цієї зони** для збільшення RR |
| **Стоп** | за **мінімум руху STB** (лонг) / **максимум руху BTS** (шорт) |
| **Ціль** | протилежний пул ліквідності (BSL/SSL) або статичні 3RR і більше |

> **Це те, що власник торгував 5 і 6 січня.** І тут прямо написано обидві його правки до мого детектора: стоп **за екстремум руху** (без буфера) і ціль — **пул ліквідності** (не дрібний свінг).

### 4. Smart Money Reversal (SMR)

| | |
|---|---|
| **Тригер** | розворотний максимум/мінімум під час реакції на HTF POI або ліквідність; розворот через Shift **з обов'язковим утворенням FVG** усередині руху STB/BTS |
| **Вхід** | на ретесті FVG усередині QM. Найвигідніше — **перетин FVG із Breaker Block (BB)** |
| **Стоп** | за максимум/мінімум сформованого розворотного руху |
| **Ціль** | Original Consolidation у MMBM/MMSM або проблемні зони (FTA) |

---

## B. Входи за зонами

### 5. Order Block Entry (OB Entry)

| | |
|---|---|
| **Тригер** | формування OB із сильним імпульсним поглинанням під час тесту HTF POI або зняття ліквідності. Злам у вигляді Shift — **необов'язковий** (вхід здійснюється до зламу). Підсилюється одночасним утворенням FVG разом із OB |
| **Вхід** | на тесті OB — від рівня **Open**, **Wick** (тіні) або **Mean Threshold (50% тіла OB)** |
| **Стоп** | за максимум/мінімум сформованої моделі OB |
| **Ціль** | найближча протилежна ліквідність, FTA або статичний 3RR |

### 6. Inversion FVG Entry (I-FVG)

| | |
|---|---|
| **Тригер** | зона FVG **пробивається (інвалідується)** тілами свічок без обов'язкового зламу Shift, після чого FVG змінює полярність на протилежну |
| **Вхід** | на ретесті пробитого FVG **з іншого (зворотного) боку** |
| **Стоп** | за максимум/мінімум сформованої моделі / екстремум руху, що пробив FVG |
| **Ціль** | протилежний пул ліквідності або FTA / 3RR |

> Це те, що власник назвав «створили ФВГ та інвертований ФВГ — це признак розвороту» в розборі 5 січня.

### 7. Continuation Model (модель на продовження)

| | |
|---|---|
| **Тригер** | вхід **тільки після первинної Reversal-моделі**, за рухом Order Flow, при підтвердженні тренду ще одним зламом (Shift) через блоки або FVG |
| **Вхід** | на відкаті (ребалансі FVG або тесті OB/Breaker) за напрямком поточного Order Flow |
| **Стоп** | за найближчий сформований максимум/мінімум |
| **Ціль** | наступний пул ліквідності за ходом Order Flow (напр. External BSL/SSL) |

### 8. Range Trade Setup (торгівля бокового руху)

| Варіант | Тригер | Вхід |
|---|---|---|
| **Агресивний** | зняття зовнішньої ліквідності (девіація) за межею боковика з тестом HTF POI | на самій девіації через LTF-модель |
| **Консервативний** | вихід на межу боковика (девіація), повернення і **закріплення тілом назад усередині** | під час повторного тесту границь боковика після повернення в діапазон |

| | |
|---|---|
| **Стоп** | за екстремум девіації (найвищий/найнижчий пік маніпуляції) |
| **Ціль** | **80% обсягу позиції** фіксується всередині боковика біля протилежної межі (або рівня 0.5), **20%** лишається на випадок істинного виходу з ренджу |

## C. Сесійні сетапи ⭐ — найближче до нашого детектора

### 9. FX Session Raid Setup

| | |
|---|---|
| **Тригер** | під час Лондонської сесії (**LOKZ з 09:00 за Києвом**) ціна знімає ключову ліквідність: **Asia High/Low, PDH/PDL або PWH/PWL** — **всередині HTF POI** |
| **Вхід** | перехід на **m5–m1**, вхід за моделлю OB Entry, QM, STB/BTS або SMR при знятті сесійної ліквідності |
| **Стоп** | за **екстремум зняття (свіп)** сесійної ліквідності на m5–m1 |
| **Ціль** | статичні 3RR **або протилежний максимум/мінімум сесії** (Asia High/Low) та PDH/PDL |

> 🔑 **Це буквально специфікація нашого детектора** — і вона містить те, чого в ньому немає: умову **«всередині HTF POI»**. Тобто свіп рахується сигналом не завжди, а лише коли він стався у зоні вищого таймфрейму. Це і є третій пропущений компонент (контекст), поряд із напрямком дня і вибором пулу.

### 10. Silver Bullet — Liquidity Sweep Setup

| | |
|---|---|
| **Тригер** | у макро-таймінги — **AM Macro 16:30–16:40** (NYSE Open), **16:50–17:10**; **PM Macro 20:10–20:40** — ціна знімає ключову ліквідність (PWH/PWL, PDH/PDL, Asia/London High/Low, Lunch High/Low, EQH/EQL) |
| **Вхід** | на **m1–m3** через консервативні моделі (STB/BTS, SMR, QM) у зазначені часові проміжки |
| **Стоп** | за екстремум зняття ліквідності в макросі |
| **Ціль** | статичні 2RR, 3RR чи 4RR або протилежна внутрішня/зовнішня ліквідність |

### 11. Silver Bullet — OF Rebalance Setup

| | |
|---|---|
| **Тригер** | Order Flow **уже зароджено** (напр. після новин о 15:30), і в макро-таймінг (16:30–17:10, 20:10–20:40) ціна рухається за трендом, **заповнюючи неефективність** (FVG / IFVG / Gap / Volume Imbalance) |
| **Вхід** | на m1–m3 при перекритті (ретесті) зони неефективності **строго в часовий макрос** |
| **Стоп** | за найближчий свінг / екстремум перед неефективністю |
| **Ціль** | статичні 2RR–3RR або протилежна ліквідність за ходом Order Flow |

### 12. FSE Open Raid Setup

| | |
|---|---|
| **Тригер** | у таймінги відкриття Франкфуртської біржі (**FSE 09:00**) або системи **Xetra (10:00)** ціна здійснює зняття ключової ліквідності (Asia High/Low, PDH/PDL, PWH/PWL, EQH/EQL) |
| **Вхід** | на **m5–m1** через Reversal-моделі (QM, I-FVG, OB, STB/BTS) у проміжку маніпуляції **09:00–10:00** |
| **Стоп** | за екстремум зняття ліквідності |
| **Ціль** | статичний 3RR або протилежна ліквідність (напр. Internal BSL/SSL) |

### 13. Commodity Session Order Flow Setup (золото, срібло, нафта)

| | |
|---|---|
| **Тригер** | на **1W–1D** визначено напрямок Order Flow. На **H1** у сесійні таймінги (09:00, 12:30, 14:00, 17:00) відбувається зняття ліквідності (SSL/BSL) **строго у бік потоку Order Flow** (тип HRLR) |
| **Вхід** | перехід на **m5**, вхід через моделі QM або I-FVG |
| **Стоп** | за екстремум зняття ліквідності на m5/H1 |
| **Ціль** | статичний 3RR або найближчі зони відкритої ліквідності (угода закривається всередині дня, **без перенесення на ніч**) |

## D. Що з цього змінює наш детектор

Три речі, яких у ньому немає, і які тут прописані явно:

| # | Правило з джерела | Стан у детекторі |
|---|---|---|
| **1** | Свіп рахується **всередині HTF POI** (модель 9) | ❌ немає — беремо будь-який свіп |
| **2** | Напрямок Order Flow задається на **1W–1D**, зняття має бути **в бік потоку** (модель 13) | ❌ немає — торгуємо обидва боки |
| **3** | Ціль — **протилежний екстремум сесії / PDH-PDL**, не будь-який рівень (моделі 9, 12) | ✅ вже виправлено у v2 за правкою власника |

Плюс дві речі, що **підтверджують** правки власника від 6 січня:
- стоп **за екстремум зняття**, без буфера — моделі 3, 9, 10, 12, 13 однаково;
- ціль — **пул ліквідності**, а не дрібна структура.

> Це перше джерело в усій роботі, яке дає **перевірювані умови контексту**, а не лише геометрію входу. Наступний прогін детектора має включати правила 1 і 2.
